# MeMoDe

MeMoDe'nin resmî portföy sitesi. Seçili web deneyimlerini ve mobil ürünleri amaç, kısa özet, teknoloji etiketleri ve ilgili bağlantılarla sunar.

## Yerel geliştirme

```bash
npm install
npm run dev -- -p 3001
```

Fikkis portal hedefi `NEXT_PUBLIC_FIKKIS_URL` ile ayarlanır.

## Vercel

Bu klasörü ayrı bir Vercel projesinin Root Directory değeri olarak seçin: `MeMoDe`.
